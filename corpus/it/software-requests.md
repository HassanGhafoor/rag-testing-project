# Software Requests

**Owner:** IT & Cyber Security, Nimbus Logistics (Pvt) Ltd, Lahore

## Purpose

This document explains how to install approved software and how to request
software that is not yet approved at Nimbus Logistics.

## Self-Service Software

The **Nimbus Software Portal** on your laptop lists all pre-approved
applications, including NimbusConnect (VPN), NimbusAuth (MFA), the Office suite,
common browsers, and standard developer tools. These install with a single click
and need no approval.

## Requesting New Software

If the software you need is not in the portal:

1. Open the **Nimbus Software Portal** and click **Request New Software**.
2. Enter the application name, version, business justification, and the cost, if
   any (in PKR).
3. Submit. The request routes to your line manager, then to IT & Cyber Security.

## Approval and Timelines

- **Free, low-risk software:** reviewed by IT within **2 working days**.
- **Paid software:** requires line-manager and Finance approval; allow **5
  working days**.
- **Software handling sensitive or client data:** undergoes a security review
  and may take up to **10 working days**.

Purchases above **PKR 30,000** per licence per year require department-head
approval in addition to Finance sign-off.

## Licensing

IT manages all software licences centrally. Do not buy software on a personal
card and claim it back — this bypasses licence tracking and security review.
Unused licences are reclaimed after **60 days** of inactivity so they can be
reassigned.

## Prohibited Software

The following are never approved:

- Cracked, pirated, or unlicensed software
- Unvetted browser extensions that read page content
- Personal file-sharing or remote-access tools not managed by IT
- Any application on the current IT blocklist

Attempting to install prohibited software is blocked by the endpoint agent and
logged.

## Removing Software

To remove an application you no longer need, use the **Uninstall** option in the
Nimbus Software Portal. If the portal will not remove it, raise a ticket with the
IT Helpdesk.
